# CR-137 — Release cadence

**Status:** Implemented
**Date:** 2026-09-24
**Requirements:** FR-399, AC-509

## Product outcome

A sentence that says release cadence is a hard block at Stage 1 and Stage 2. The block holds when the sentence cites a different fact, and when it cites nothing. A deletion cadence does not block. Defect triage with QA engineering does not block.

## Why

Work experience does not use the phrase release cadence. The before-fix Classlink resume says he guided release cadence and cites the first-pass QA fact.
