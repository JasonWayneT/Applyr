# CR-138 — Testing analytics

**Status:** Implemented
**Date:** 2026-09-24
**Requirements:** FR-400, AC-510

## Product outcome

A sentence that says testing analytics is a hard block at Stage 1 and Stage 2. The block holds when the sentence cites a different fact, and when it cites nothing. A Pendo product-analytics sentence does not block.

## Why

Work experience does not use the phrase testing analytics. The before-fix Classlink resume applies it to the Parallels test work and cites ACC-214.
