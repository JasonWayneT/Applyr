# CR-139 — Visible codename

**Status:** Implemented
**Date:** 2026-09-24
**Requirements:** FR-401, AC-511

## Product outcome

A capitalized Visible after a space is a hard block at Stage 1 and Stage 2. The block holds when the sentence cites a different fact, and when it cites nothing. Lowercase visible does not block.

## Why

Work experience says never print that name. The before-fix Obie resume prints it in the middle of a sentence.

- Changing the evaluator
- A holdout run
