# CR-144 — Contributed claim does not say designed and built

**Status:** Implemented
**Date:** 2026-09-24
**Requirements:** FR-407, AC-518

## Product outcome

Before the hiring-manager pass, a contributed claim that says designed or built is reworded to contributed to. An owned claim that says built stays. The warning still fires on the original wording.

## Why

Holdout 6 parked because a letter said a contributed project was designed and built. The approved wording is contributed to.

## Out of scope

- Changing the evaluator
- Treating the warning as accepted without an edit
- A holdout run
