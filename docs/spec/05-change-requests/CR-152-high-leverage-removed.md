# CR-152 — high-leverage is not plain language

**Status:** Implemented
**Date:** 2026-09-24
**Requirements:** FR-415, AC-526

## Product outcome

A summary that says high-leverage loses that compound. Standalone leverage becomes use. data-driven stays.

## Why

Holdout 14 failed Stage 1 because the summary said high-leverage. The hyphen did not hide the banned word.

## Out of scope

- Allowing the compound
- Changing the evaluator
- A holdout run
