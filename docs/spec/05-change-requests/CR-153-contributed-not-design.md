# CR-153 — A contributed claim does not say design

**Status:** Implemented
**Date:** 2026-09-24
**Requirements:** FR-416, AC-527

## Product outcome

A contributed claim that says design is reworded to contributed to. An owned claim that says built stays. The warning still fires on the original wording.

## Why

Holdout 15 parked because a letter said a contributed project was a design. The earlier rewrite only caught designed and built.

## Out of scope

- Changing the evaluator
- Treating the warning as accepted without an edit
- A holdout run
