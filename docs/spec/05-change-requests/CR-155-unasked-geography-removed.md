# CR-155 — Unasked geography leaves the draft

**Status:** Implemented
**Date:** 2026-09-24
**Requirements:** FR-418, AC-529

## Product outcome

When a posting never asks for geography, a country list and a geography use of distributed are removed before Stage 1 verify. A line about distributed data systems stays. A posting that asks for distributed work keeps the line. The warning still fires on the original wording.
